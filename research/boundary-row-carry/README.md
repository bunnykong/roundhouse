# Boundary row carry

Native source for [F67](https://github.com/bunnykong/roundhouse/blob/fixpoint-research/docs/research/facts.md#f67).

Boundary carry and placeholder retraction fail the settlement and forbidden-event gates, with and without deduplication.

The public controls are `RH_DEFERRED_DEFER`, `RH_DEFERRED_STRATIFY` and `RH_DEFERRED_NDEDUP`.
`RH_DEFERRED_CARRY=1` enables boundary carry.
The lab receipt retains the negative evidence and limits. This public spelling port has not been compiled.
