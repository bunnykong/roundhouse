{%- comment -%} G. Join in {%- endcomment -%}

Join in

Make one gap easier to understand.

A small reproducer, a clearer error report, a test or a documentation fix all help. Your first contribution doesn’t have to be a compiler patch.

  • I know RailsTake one untriaged failure. Write the smallest Rails example that shows it, with the answer Rails gives and the one we give.
  • I like writing testsPick a rule with no matches and rerun its original case: is it fixed, or did the failure change?
  • I want to work on the compilerChoose a named group, find its stage in the ownership map, and land the fix with a regression test.
  • I’m new hereSet up a checkout and try a command from the guide. If a step confused you, fixing it helps the next person.
